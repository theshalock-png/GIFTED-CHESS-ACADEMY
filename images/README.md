# Images Folder Guide

Drop your photos into the correct sub-folder and the website will automatically display them.
Keep filenames **exactly as listed below** (lowercase, no spaces).

---

## 📁 images/merch/
Product photos for the Shop page.

| Filename              | Used for                        | Recommended size  |
|-----------------------|---------------------------------|-------------------|
| board.jpg             | Premium Wooden Chess Board      | 800 × 800 px      |
| piece-set.jpg         | Staunton Piece Set              | 800 × 800 px      |
| combo.jpg             | Board + Pieces Combo            | 800 × 800 px      |
| clock.jpg             | Digital Chess Clock             | 800 × 800 px      |
| tshirt.jpg            | Branded T-Shirt                 | 800 × 800 px      |
| hoodie.jpg            | Chess Hoodie                    | 800 × 800 px      |
| cap.jpg               | Chess Cap                       | 800 × 800 px      |
| bag.jpg               | Chess Piece Bag                 | 800 × 800 px      |
| notebook.jpg          | Chess Notation Notebook         | 800 × 800 px      |

**Tips:**
- Square photos look best (1:1 ratio).
- JPG or PNG both work fine.
- Keep file size under 300 KB for fast loading.

## How to Update a Photo

1. Take your photo and rename it to the exact filename listed above.
2. Drop it into the correct folder.
3. Open the site in a browser — the new photo appears automatically.
4. No code changes needed.
